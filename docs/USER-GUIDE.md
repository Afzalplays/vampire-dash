# User guide

The dashboard is currently a preview. API registration/login starter endpoints are available for local development only. User-facing server provisioning, console, file manager, backup restore, plugin installer, player controls and wallet top-ups are not available yet.

Planned user workflow: register and verify account, enable MFA, create a server in an available node location, manage server resources and files, and view wallet/payment history. Do not submit real payment or customer data to this development build.
